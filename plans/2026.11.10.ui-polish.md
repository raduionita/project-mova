## 3. Component definitions and exact values

- Goal tile: square with height equal to width, grid capped at 400 pt and centered, icon 32 pt, primary label slot 14 pt.
- Choice card: `iconSize` 17 default, `iconBoxSize` 32 default, content padding 13x12 default. Experience passes 22, 40, and 16x16.
- Today header: 48 pt stack, calendar leading, chip centered, bell trailing. Streak tag sits beside the Planned or Recovery tag.
- Set row: height 60, padding 8x10. Weight and reps boxes 40 pt tall, radius 8, `surfaceAlt` fill, `line` border, `blue` border when active. Value text stays `bodyStrong`. Check is 36 pt and rightmost.
- Swipe: end to start, orange panel with a trash icon. The removal callback is invoked once and the row returns to rest if the provider rejects the change.
- Numeric sheet: selecting the whole initial value on open.
- Avatar: 64 pt lime circle, icon 32 pt in `limeInk`, person fallback.

## 6. Risks

- Square tiles can overflow on very wide web windows, so the grid is capped.
- Sharing `AppChoiceCard` means the new options must default to today's values or gender and Edit profile shift.
- Swipe removal is destructive with no undo. A rejected removal keeps the set and snaps the row back.
- Removing the X must not strand screen reader users, so removal stays exposed as a semantics action.
