## 1. Request, decisions, and product rules

### 1.1 Original user request

The app must work for people whose training schedules do not line up with weekdays, for example 3 workouts plus 1 rest, 1 workout plus 1 rest, or chaotic routines. "How often do you train?" must mean average days per week and act as a guide, not fixed weekdays.

The user also asked:

- Adjust and transform onboarding and the plan screen.
- Treat any day that is not logged as a rest day.
- Today should have a begin workout action.
- Clarify the purpose of the exercise detail screen, whose primary button is disabled.
- Clarify the purpose of `/train`, which lists exercises and adds them to nowhere.
- Keep `/me`, `/social`, and `/progress`, but expand Progress with faded placeholder cards for trackable metrics, including metrics hidden because there is no data.
- Add a planner screen even though schedules can be arbitrary.
- Make Today the main screen for starting a workout, walk, or routine.
- Replace Train with a calendar overview of when and what was done, integrating `/train` elsewhere.
- Add a Today suggestion card based on recent training, covering common splits such as full body, upper-lower, and 3-day splits.

### 1.2 Decisions taken with the user

- Bottom navigation becomes Today, Calendar, Progress, Social, Me. Plan and Exercises are secondary screens.
- Keep both day streak and weekly consistency.
- With a plan, Start workout prefills the logger with the suggested plan session.
- Without a plan, Start workout opens a focus drawer. Focus options include All, Full body, Upper, Lower, Push, Pull, Legs, Chest, Back, Shoulders, Arms, and Core.
- After focus selection, show a few faded suggested exercises that can be added quickly.
- Add exercise opens a filtered library. Filters can be switched or turned off.
- Calendar shows previous workouts with type icons, makes today obvious, and shows future suggested days with dashed circles.
- All actionable faded placeholders have a quick add button.
- Add `Week starts on` to Me, relative to locale by default, with a manual override.
- Week start affects the calendar and every week-based surface in the app.

### 1.3 Product rules

- The plan is an ordered rotation of 1-7 sessions. `daysPerWeek` is an average target, not fixed weekdays.
- Any past or current day without a completed workout is a rest day. Rest never blocks training.
- Future dashed days are suggestions only. They are never logged, planned, or counted as rest.
- Today always has a next action: Continue, Start workout, or Train again.
- No primary button is disabled because there is no active workout. Every exercise action has a valid destination.
- Week start is locale-aware by default, with a manual override.
- All data stays local. No Firebase, no cloud sync.
- Routines remain reusable templates. They are not scheduled sessions.

## 2. Data model, services, and navigation

### 2.1 Training plan v2

`TrainingPlan.schemaVersion` becomes `2`.

`PlanDay` gains:

- `order`
- `slotKey`
- legacy nullable `weekday` for migration only

`trainingDays` is kept only for reading v1 plans. New plans do not write it. Plan IDs no longer include weekdays.

Stable slot keys:

- 1 day: `full`
- 2 days: `full-a`, `full-b`
- 3 days: `push`, `pull`, `legs`
- 4 days: `upper-a`, `lower-a`, `upper-b`, `lower-b`
- 5 days: `push`, `pull`, `legs`, `upper`, `lower`
- 6 days: `push-a`, `pull-a`, `legs-a`, `push-b`, `pull-b`, `legs-b`
- 7 days: the 6-day keys plus `recovery`

### 2.2 Workout snapshot v2

Add to `WorkoutSession`:

- `displayTitle`
- `sourceLabel`
- `slotKey`
- `muscleGroups`
- `focusPromptShown`

Add to `SessionExercise`:

- `primaryMuscle`
- `secondaryMuscles`

When a workout completes, these values are written once. Calendar, Progress, and suggestions read the snapshot first. Legacy sessions fall back to the current plan, routine, or exercise library.

### 2.3 Rotation rule

- The next session is the slot after the most recently completed plan session.
- Only completed sessions created after `plan.generatedAt` advance the current rotation.
- Reordering uses the new order and the same last completed slot.
- Regeneration resets rotation to Day 1 and shows a short notice.
- If the last completed slot no longer exists, fall back to Day 1.
- Routines, empty workouts, and walks do not advance the rotation.

### 2.4 Week start

- `AppSettings.schemaVersion` becomes `2`.
- Add `int? weekStart`, where `null` is automatic and `1-7` is an explicit ISO weekday.
- Add `SettingsProvider.setWeekStart`.
- Add `WeekStartResolver`:
  - explicit override first
  - otherwise `MaterialLocalizations.firstDayOfWeekIndex`
  - Flutter `0=Sunday..6=Saturday` converts to ISO `1=Monday..7=Sunday`
  - fallback Monday
- Add `flutter_localizations` and global localization delegates.
- `DateKeys.weekStart` accepts the effective week start instead of hardcoding Monday.

### 2.5 New services

- `SessionSuggestionService`: next rotation session, recovery warning, muscle neglect, no-plan recommendation.
- `SuggestionCadence`: dates for the next 3 suggested sessions.
- `WeekStartResolver`: locale mapping and fallback.
- `MuscleBalanceService`: volume by muscle over the last 28 days.
- `WeekStreakService`: completed weeks meeting target and current-week progress.
- `ProgressPhotoStore`: local thumbnail storage abstraction.

### 2.6 Navigation

Bottom navigation: Today, Calendar, Progress, Social, Me.

Routes:

- `/calendar` new
- `/plan` new
- `/exercises` new
- `/train` aliases to `/calendar`
- `/train/exercises/:id` stays
- `/train/routines...` stays

`AppTab.train` becomes `AppTab.calendar`. Exercise routes highlight Calendar. Routine routes highlight Plan. The routine builder stays full-screen with no bottom bar.

## 4. Screen and interaction definitions

### 4.1 Onboarding

**Schedule step**

- Title stays `How often do you train?`
- Remove the weekday selector.
- Keep the 1-7 stepper.
- Copy explains: average target, rotation, start any day, unlogged days are rest.
- `trainingDays` is removed from the draft.

**Plan preview**

- Title becomes `Your plan`.
- Cards show `Day 1`, `Day 2`, and the session name and muscles.
- Footer explains the rotation and rest days.
- `Edit schedule` returns to the frequency step.
- `Start using Mova` creates the rotation and opens Today.

### 4.2 Today

Always show a primary state:

- Active session: `Continue workout`
- Completed today: `Trained today` plus `Train again`
- Otherwise: `Next up: [session]` plus `Start workout`
- No plan: `Start workout` opens the focus flow

Additional behavior:

- `Choose another session` lists rotation sessions, routines, empty workout, and walk.
- Starting from a plan prefills the logger with that plan day.
- Suggestion copy is brief: `Because you trained Push 2 days ago`, or `You have not trained legs in 8 days`.
- Recovery is a warning, never a block.
- Steps, quick actions, and stats remain.

### 4.3 Focus flow

When a new empty workout has no exercises:

- Show the focus drawer once.
- Options: All, Full body, Upper, Lower, Push, Pull, Legs, Chest, Back, Shoulders, Arms, Core.
- Show 4-6 faded suggested exercises with a plus button.
- `Add exercise` opens the library filtered by focus.
- Filter chips stay switchable, including `All`.
- Dismissing leaves a valid empty workout.
- Persist `focusPromptShown` so it does not reappear on rebuild or resume.
- Skip the drawer when seeded from a plan, routine, or exercise.

### 4.4 Planner

New `/plan` screen:

- Frequency chips 1-7
- Split style: Auto, Full Body, Upper-Lower, PPL
- Ordered rotation list with `Day 1..N`, session name, muscles, exercise count, and `Next` badge
- Expandable exercise preview
- Up/down reorder
- Start session
- Regenerate with confirmation
- `My routines` with create, start, and view all

Frequency and split changes are staged. Nothing changes until `Regenerate`.

### 4.5 Calendar

Month grid using the effective week start:

- Past logged workouts show an icon for plan, routine, walk, or empty.
- Multiple sessions show a count or stacked markers.
- Today gets an accent ring and `Today` label, plus a check when trained.
- The next 3 suggested sessions get dashed circles and a small icon.
- Suggested days are never counted as logged or rest.
- No 14-day projection.

Day tap:

- Past logged: session list with title, source, duration, volume, and history detail.
- Past empty: `Rest day`, no workout logged.
- Today: same as past, plus `Start workout`.
- Future suggested: `Suggested: [session]`, with `View session` and optional `Start now`.

Header actions:

- Plan
- Exercises

### 4.6 Exercise library

New `/exercises` screen:

- Search
- Focus chips with `All`
- Equipment and muscle metadata on rows

Row behavior:

- Active workout: add directly with default sets and show `Added` plus `View`.
- No active workout: choice sheet with:
  - Start workout with this
  - Add to routine
  - View details

### 4.7 Exercise detail

Always actionable:

- Active workout and not in session: `Add to current workout`
- Active workout and already in session: `Already in workout` plus `View in workout`
- No active workout: `Start workout with this exercise`

Secondary actions:

- Add to routine
- View history

View history opens a filtered sheet with recent sets, weights, reps, and dates.

### 4.8 Progress

Sections:

**Training**

- Day streak and week streak
- Weekly consistency: sessions this week vs target
- Weekly volume for the current calendar week
- Muscle balance for the last 28 days
- Personal records

**Body**

- Body weight
- Measurements
- Progress photos

**Wellness**

- Nutrition
- Sleep
- Resting heart rate

Behavior:

- Real metrics are normal when data exists.
- Real metrics are faded when empty, with a quick add action.
- Future metrics are faded with a quick add action.
- Use the Social placeholder style: `Opacity 0.72` plus `DashedBorder`.
- Keep labels and buttons fully readable.
- Use sections and a 2-column grid for compact placeholders.
- Avoid repeating a large `Start workout` button on every card.

Quick add:

- Consistency, weekly volume, muscle balance, PR wall: `Start workout`
- Strength score: `Add body weight`
- Body weight: existing weight sheet
- Measurements: numeric sheet
- Nutrition: calories and protein
- Sleep: hours and minutes
- Resting heart rate: bpm
- Photos: local picker

### 4.9 Week start UI

- Add `Week starts on` to `/me`, after `Units`.
- Value examples: `Automatic (Monday)`, `Sunday`, `Saturday`.
- Tapping opens `WeekStartSheet` with Automatic plus Monday through Sunday.
- Add the same control in a `Calendar` section of `/me/settings`.
- Use one provider and one sheet.

Affected surfaces:

- Calendar column order and grid
- Weekly consistency
- Week streak
- Weekly volume
- Week labels
- Optional reminder day display order

Reminder scheduling stays tied to the actual weekday.
